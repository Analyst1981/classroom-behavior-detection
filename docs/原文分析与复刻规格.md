## 一、原文信息提取（逐条对应）

### 1. 项目定位
基于**改进 YOLO（PyTorch）**与**大模型（DeepSeek / Qwen）**结合的课堂行为检测与智能分析系统，
支持单图 / 批量 / 视频 / 实时摄像头四类输入，含前后端完整源码与环境配置。

### 2. 功能目标（功能清单）
| 原文功能 | 本项目实现位置 |
|---|---|
| 单张图片检测（返回 outImg、label、confidence、耗时） | `ai-service/app.py:/api/detect/image`；前端 `ImageView.vue` |
| 图片文件夹批量检测（打包上传、后台预测、批量结果） | `ai-service/app.py:/api/detect/batch`（zip / 多文件）；前端 JSZip 打包 |
| 上传视频并返回带标注视频（MJPEG 实时流 + 后台转码保存） | `ai-service/video_pipeline.py` + FFmpeg 管道编码 H.264 |
| 实时摄像头检测（实时标注 + 保存录像） | `ai-service/app.py:/api/camera/*`；前端 `CameraView.vue` |
| AI 智能建议（DeepSeek / Qwen：学习状态评估、课堂管理建议） | `ai-service/llm.py`（OpenAI 兼容协议 + 本地规则引擎兜底） |
| 检测记录管理（历史记录、删除、查看） | `backend` JPA + MySQL/H2；前端 `RecordsView.vue` |
| PDF 报告导出（检测详情 + AI 建议） | `ai-service/report.py`（reportlab 中文 CID 字体，Pillow 兜底） |
| 可定制：行为类别、阈值、输出格式、UI 文案 | `config.py` 环境变量 + `data/classroom.yaml` + 前端文案 |

### 3. 技术架构（B/S 四层）
```
浏览器(Vue3 + Element Plus + Pinia + Axios)
        │  HTTP / MJPEG
Spring Boot 后端(记录管理、转发、PDF 代理) ── MySQL(可替换为 H2)
        │  HTTP
Flask AI 中台(PyTorch/YOLO 推理、视频流水线、LLM 调用、PDF 生成)
```
- 主体语言：Python(PyTorch, Flask)、Java(Spring Boot)、JavaScript(Vue3)
- 数据库：MySQL（本项目同时提供 H2 兜底）
- 前端：Vue3 + Element Plus + Pinia + Axios
- 模型：改进 YOLOv5/YOLOv8/YOLO11/YOLO12（PyTorch，ultralytics 统一接口）
- 其他：SocketIO（进度推送，本项目为可选降级为轮询）、FFmpeg（视频转码）、JSZip（前端文件夹压缩）

## 二、与原文的差异说明（重要，避免误解）

1. **权重来源**：原文称「交付时包含已训练的 6 类权重」。本项目未附带私有权重，因此：
   - 若 `ai-service/models/best.pt` 存在 → 真实 6 类推理；
   - 否则自动下载并使用官方通用权重 `yolov8n.pt`，把检出的 `person` 确定性映射到 6 类行为
     （结果标注 `generic=True`）；
   - 若画面中未检出目标，则用内置演示引擎（肤色 + 边缘显著性）补位，返回 `fallbackDemo=true`；
   - 提供 `train.py` 与 `data/classroom.yaml`，用自有数据集训练后即切换为真实检测。
2. **SocketIO**：原文用于实时进度。本项目保留 SocketIO 支持（Flask 侧），
   但不强制依赖；不支持时自动降级为前端轮询（`flask_socketio` 在部分 Python 环境导入失败）。
3. **数据库**：原文「MySQL（可替换）」。本项目默认 MySQL 8，并提供 H2 profile 兜底，
   便于无数据库环境下直接启动验证。

## 三、目录结构
```
classroom-behavior-detection/
├── ai-service/                # Flask + PyTorch 推理服务（端口 5000）
│   ├── app.py                 # 接口入口
│   ├── detector.py            # 检测引擎（ultralytics / demo）
│   ├── video_pipeline.py      # 视频与摄像头流水线（MJPEG + FFmpeg）
│   ├── llm.py                 # DeepSeek / Qwen + 本地规则引擎
│   ├── report.py              # PDF 报告（reportlab / Pillow）
│   ├── config.py              # 全部可调参数（环境变量）
│   ├── train.py               # 6 类行为模型训练
│   ├── tools/make_demo_data.py# 演示素材生成
│   ├── data/classroom.yaml    # 数据集定义
│   ├── models/                # 权重目录（放入 best.pt 即切换真实模型）
│   ├── outputs/               # 检测结果输出
│   └── demo_data/             # 演示图片 / zip / 视频
├── backend/                   # Spring Boot 后端（端口 8080）
│   └── src/main/java/com/cbd/{config,controller,service,entity,repository,dto,exception}
├── frontend/                  # Vue3 + Element Plus（端口 5173）
│   └── src/{api,router,stores,views,components,styles}
├── db/schema.sql              # MySQL 建库建表脚本
├── mvn/settings.xml           # Maven 阿里云镜像（加速下载）
└── scripts/                   # 启动 / 停止 / 构建 / 验证脚本
```
